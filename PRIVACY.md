# Privacy Policy

**Last updated:** March 7, 2026  

QuizTeX does not collect, store, or transmit personal data. Rendering uses **MathJax bundled inside the extension** (no network requests for math typesetting).

**Chrome Web Store:** Use the HTML version for your listing’s privacy policy URL once hosted (see [`docs/privacy-policy.html`](docs/privacy-policy.html) and [`docs/STORE_SUBMISSION.md`](docs/STORE_SUBMISSION.md)).

## What the extension does

- Runs only on Quizlet websites (`https://*.quizlet.com/*`).
- Reads page content already shown in the browser to find raw LaTeX and typeset it locally.
- Does not send flashcards, answers, or account data to the developer.

## Data handling

- No analytics, tracking, or telemetry.
- No remote API calls made by the extension for rendering.
- No cookies are set by the extension.
- No user database or cloud sync operated by QuizTeX.

## Permissions rationale

- **Host access (Quizlet):** Required to inject the content script on study pages.
- **Frames:** Some Quizlet modes use nested frames; access is needed for consistent rendering.

## Third parties

Quizlet’s own services are governed by Quizlet’s privacy policy. This extension is independent of Quizlet Inc.

## Changes

If these practices change, this policy will be updated before a new Chrome Web Store release.
