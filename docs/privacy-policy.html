QuizTeX — Privacy Policy

Last updated: March 7, 2026 · This extension is distributed via the Chrome Web Store.

QuizTeX does not collect, store, or transmit personal data. All rendering happens locally in your browser using bundled scripts (MathJax) included with the extension.

What the extension does

  • Runs only on Quizlet websites (https://*.quizlet.com/*).
  • Reads page content that is already displayed to you so it can find raw LaTeX delimiters and typeset them as math.
  • Does not send your flashcards, answers, or account information to the developer or third parties.

Data handling

  • No analytics, tracking, advertising identifiers, or telemetry.
  • No remote API calls are made by the extension for rendering (MathJax is bundled; see technical note below).
  • No cookies are set by the extension.
  • No separate user database or cloud sync operated by this extension.

Permissions (why they are needed)

  • Site access (Quizlet): Required to inject the content script that runs MathJax on study pages you open.
  • Frames: Some Quizlet modes load content in nested frames; frame access is needed so math renders consistently.

Third parties

This extension uses the MathJax library bundled inside the extension package (no network fetch for math rendering). Quizlet’s own services are governed by Quizlet’s privacy policy, not this policy.

Children

The extension is a general-purpose study aid. It does not knowingly collect personal information from anyone, including children.

Changes

If these practices change, this policy will be updated before a new version is published to the Chrome Web Store.

Contact

Questions about this policy: open an issue on the QuizTeX GitHub repository or use the contact channel listed on the Chrome Web Store developer page.

QuizTeX is an independent project and is not affiliated with or endorsed by Quizlet Inc.
